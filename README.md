# 🧮 Calculator App

> A desktop calculator application built with C# and Windows Forms.

## Overview

Calculator App is a Windows desktop project demonstrating event-driven UI programming, numeric input handling, arithmetic operations, and a structured Windows Forms interface.

## Technology

- C#
- .NET desktop tooling
- Windows Forms
- Visual Studio solution and project files

## Run Locally

Open [`calculator/calculator.sln`](./calculator/calculator.sln) in Visual Studio and press **F5**.

## Project Structure

```text
calculator/
└── calculator/
    ├── calculator.cs             # Calculator logic and event handlers
    ├── calculator.Designer.cs   # Windows Forms layout
    └── Program.cs                # Application entry point
```
